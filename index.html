FTC Decode Robot

Team 19498 · Mechanical Design Lead / Software Lead / Systems Engineer · Sept 2025 – Apr 2026

V0 — Prototype

Initial proof of concept focusing on basic chassis mechanics and layout.

V1 — First Competition Build

Evolved the V0 prototype into a first complete, competition-ready robot.

V2 — Competition Robot

Set the Canadian scoring record for the Decode season.

Technical Stack & Tooling

  • CAD & Simulation: Onshape, Custom Assembly Configurator, Finite Element Analysis (FEA) for pocketed plates.
  • Manufacturing: CNC Routing (0.25" Polycarbonate, 4mm 6061 Aluminum), 3D Printing (Markforged Onyx / PETG), Laser Cutting.
  • Control & Navigation: Java, Android Studio, Road Runner (Motion Profiling), OpenCV (Pipeline Tuning), Three-Wheel Localized Odometry, PID control loops.
  • Hardware Ecosystem: goBILDA 5203 Series Yellow Jacket Motors, Rev Robotics Control Hub, 24mm Viper Slide Kits.

Core Subsystems

1. Drivetrain & Localization

  • Designed a 4-motor Mecanum drivetrain geared at 19.2:1 (312 RPM), balancing maximum sprint speed with high pushing torque.
  • Fabricated a custom spring-loaded suspension rig for three-wheel dead-wheel odometry pods, maintaining constant floor contact.
  • Result: Achieved a repeatable tracking error of under 0.5 inches across a 30-second autonomous pathing routine.

2. Rigging & Multi-Stage Lift System

  • Engineered a continuous-backstring rigging system using 4-stage heavy-duty linear slides driven by a 435 RPM motor with a custom-turned winch drum.
  • Utilized FEA testing to pocket the aluminum side plates, reducing structural weight by 18% without sacrificing torsional rigidity.
  • Result: Reduced full-extension vertical travel time to 0.9 seconds, increasing scoring capacity during the End Game period.

3. Active Intake & Smart Grabber

  • Prototyped a compliant-wheel intake using 35A durometer TPU rollers to handle variations in game element alignment.
  • Integrated a Rev Color Sensor V2 inside the bucket structure to automate intake motor shutoff immediately upon element collection.
  • Result: Eliminated driver reaction lag, reducing element collection time to an average of 0.4 seconds per pickup.

Performance

Cycle speed11.2 sec (target 15)

Co-axial Swerve Drive

Summer 2025 · Mechanical design + programming

An FTC-legal swerve module — drive and steering share one axis, so each wheel rotates a full 360°. I designed the module in CAD (Fusion 360 / Onshape) and wrote the control code in Java.

An absolute encoder on the steering axis means the robot always knows its wheel orientation on boot — no homing routine. Steering runs on PID loops tuned against encoder feedback.

Steering latency0.1 s
Top speed3.5 m/s
MotorsgoBILDA
Control hubREV Control Hub
